# 🌤️ Painel do Clima (Climate Dashboard)

Aplicação web desenvolvida para consulta de clima em tempo real e gestão de cidades favoritas, integrada com API externa e banco de dados em nuvem.

---

## 🚀 Funcionalidades (CRUD Completo)

- **🔍 Busca em Tempo Real (API Fetch):** Consulta coordenadas e dados meteorológicos globais utilizando a **Open-Meteo API**.
- **➕ Adicionar Favoritos (Create):** Grava a cidade, país e temperatura atual diretamente no banco de dados **Supabase**.
- **📋 Listagem Dinâmica (Read):** Carrega e exibe a lista atualizada de cidades salvas no banco de dados.
- **🗑️ Remover Favoritos (Delete):** Permite excluir cidades cadastradas do banco com atualização imediata da interface.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3 e JavaScript (ES6 Modules)
- **API de Clima:** [Open-Meteo Geocoding & Weather API](https://open-meteo.com/)
- **Backend / Banco de Dados:** [Supabase](https://supabase.com/) (PostgreSQL)
- **Controle de Versão:** Git e GitHub

---

## 🗄️ Estrutura do Banco de Dados

A aplicação utiliza a tabela `cidades_favoritas` no Supabase com a seguinte estrutura:

```sql
CREATE TABLE public.cidades_favoritas (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    nome_cidade TEXT NOT NULL,
    pais TEXT NOT NULL,
    temperatura NUMERIC NOT NULL
);
